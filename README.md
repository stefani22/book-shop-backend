# Лабораториски вежби - ЕМТ 

📌 Project Description
This is a REST API for a book rental system with JWT authentication and role-based authorization.

🛠 Technologies Used
- Java
- Spring Boot 
- Spring Security
- Spring Data JPA
- JWT Authentication
- PostgreSQL
- Flyway
- Swagger UI

✨ Functionalities

1. Books Management
    - View all books
    - Filter books by state
    - Add, edit, delete books (Admin only)

2. Authors Management
    - View all authors
    - Add, edit, delete authors (Admin only)

3. Countries Management
    - View all countries
    - Add, edit, delete countries (Admin only)

4. Wishlist
    - Each user has a personal wishlist
    - Add and remove books from wishlist

5. Authentication System
    - Login and Register
    - JWT Authentication
    - Role-based authorization

🔐 Security
- Spring Security
- JWT Authentication
- Role-based authorization

Roles:
- ROLE_ADMINISTRATOR
- ROLE_USER
